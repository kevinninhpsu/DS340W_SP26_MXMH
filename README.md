# DS340W_SP26_MXMH
# Mental Health Screening Utilizing Music and AI

This repository contains the final code, dataset splits, outputs, and supporting materials for our DS340W final project on predicting mental health outcomes using music listening behavior and Spotify audio features.

## Project Overview

The goal of this project is to improve upon a parent paper that used only self-reported music behavior from the MXMH dataset to predict anxiety, depression, insomnia, and OCD. Our novelty approach integrates Spotify audio features with the original survey data and evaluates multiple machine learning models in a reproducible pipeline.

We compare:
- a parent paper reproduction baseline
- a survey-only baseline
- an enhanced survey + Spotify feature pipeline

## Research Question

Can objective Spotify audio features improve mental health classification when combined with self-reported music listening behavior?

## Models Evaluated

The final pipeline evaluates the following models:
- Logistic Regression
- Linear SVM
- Random Forest
- Histogram Gradient Boosting

## Evaluation

Models are evaluated using:
- Stratified 5-fold cross-validation
- F1 score
- Accuracy
- Balanced accuracy
- Precision
- Recall

We also include:
- ablation analysis
- feature importance
- confusion matrix visualization
